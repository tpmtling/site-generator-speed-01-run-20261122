A faster drop-in for make.fun's own makefun-site 1.0.0: it answers exactly as makefun-site does on every case, byte for byte, but renders Markdown without token objects, escapes inline text in whole chunks instead of one regex per character, caches slugs, and counts words without building a match array. About 1.6x faster than the house baseline on the practice set.

## Run it

```sh
node main.ts
```
